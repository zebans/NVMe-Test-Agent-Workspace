# Firmware Image Download - Opcode 11h

Base Spec 2.0 Admin command reference for downloading all or part of a firmware or Boot Partition image.

Use this folder when the question is about `DPTR`, `NUMD`, `OFST`, `FWUG` alignment/granularity, out-of-order image pieces, Boot Partition ordering, overlapping ranges, or image discard rules.
