# Firmware Image Download Cross-Spec Boundary

## This Folder Owns

- Base Spec 2.0 Firmware Image Download command semantics.
- `DPTR`, `NUMD`, `OFST`, and `FWUG` field relationship.
- Image piece ordering / overlap rules stated by Base Spec.
- Firmware Image Download status surface.

## This Folder Does Not Own

- PyNVMe API call syntax.
- Firmware image binary format.
- Full firmware activation process in section 3.11.
- Full Boot Partition process in section 8.2.
- Platform reset orchestration.
