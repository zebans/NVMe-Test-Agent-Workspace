# Virtualization Management Cross-Spec Boundary

## This Folder Owns

- Base Spec 2.0 Virtualization Management command fields and statuses.
- `CNTLID`, `RT`, `ACT`, `NR`, and `NRM` meanings.
- Base command-level resource validation conditions.

## This Folder Does Not Own

- PyNVMe API call syntax.
- Full virtualization architecture and resource model in section 8.26.
- Controller implementation resource allocation policy.
- Test flow sequencing for enabling/disabling virtualization.
