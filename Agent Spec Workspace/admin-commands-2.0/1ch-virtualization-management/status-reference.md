# Virtualization Management Status Reference

| Status | Meaning |
|---|---|
| `Invalid Controller Identifier` | Invalid `CNTLID`, or `CNTLID` does not correspond to required primary/secondary controller for the action. |
| `Invalid Secondary Controller State` | Requested secondary-controller action is invalid for current secondary/primary controller state. |
| `Invalid Number of Controller Resources` | `NR` is invalid, such as exceeding flexible total or flexible secondary maximum resources. |
| `Invalid Resource Identifier` | Requested resource range does not exist, is private/unsupported, or is currently in use/unavailable. |
