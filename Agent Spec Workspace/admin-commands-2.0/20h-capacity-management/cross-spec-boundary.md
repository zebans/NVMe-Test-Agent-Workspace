# Capacity Management Cross-Spec Boundary

## This Folder Owns

- Base Spec 2.0 Capacity Management command fields and operation table.
- `Element Identifier`, `Operation`, `Capacity Lower`, and `Capacity Upper`.
- Command-level status meanings.
- High-level operation effects stated by section 5.3.

## This Folder Does Not Own

- PyNVMe API call syntax.
- Full Capacity Configuration Descriptor structure.
- Full extended capability behavior in section 8.3.
- Namespace deletion flow details outside this command.
