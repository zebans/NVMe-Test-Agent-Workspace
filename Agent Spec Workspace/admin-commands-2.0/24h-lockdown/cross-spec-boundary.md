# Lockdown Cross-Spec Boundary

## This Folder Owns

- Base Spec 2.0 Lockdown command fields and status meanings.
- `OFI`, `IFC`, `PRHBT`, `SCP`, and UUID Index rules.
- Base invalid field conditions for interface/scope combinations.

## This Folder Does Not Own

- PyNVMe API call syntax.
- Full Command and Feature Lockdown behavior in section 8.4.
- Vendor specific Feature Identifier semantics.
- Management Interface / PCIe command set detailed opcode behavior.
