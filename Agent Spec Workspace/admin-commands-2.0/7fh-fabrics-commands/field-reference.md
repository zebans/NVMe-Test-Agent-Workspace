# Fabrics Commands Admin Opcode Field Reference

| Field surface | Base meaning | Detailed owner |
|---|---|---|
| Admin opcode | `7Fh` identifies Fabrics Commands. | Base Admin opcode table |
| Fabrics command type | Selects Property Set, Connect, Property Get, Authentication, Disconnect, or vendor-specific Fabrics behavior. | `fabrics-base-2.0/commands` |
| Command-specific fields | Not inferable from opcode `7Fh` alone. | Specific Fabrics command folder |
