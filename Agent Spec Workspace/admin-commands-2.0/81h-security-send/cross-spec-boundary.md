# Security Send Cross-Spec Boundary

## This Folder Owns

- Base Spec 2.0 Security Send command semantics.
- `DPTR`, `SECP`, `SPSP1`, `SPSP0`, `NSSF`, and `TL` meanings.
- Security Protocol `EAh` NVMe-specific selector values from Base Spec.
- Base/SPC-5 boundary statement.

## This Folder Does Not Own

- PyNVMe API call syntax.
- SPC-5 security protocol payload definitions.
- TCG / RPMB protocol payload details.
- Security Receive response payload format for a specific protocol.
