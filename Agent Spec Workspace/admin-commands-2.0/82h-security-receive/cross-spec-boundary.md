# Security Receive Cross-Spec Boundary

## This Folder Owns

- Base Spec 2.0 Security Receive command semantics.
- `DPTR`, `SECP`, `SPSP1`, `SPSP0`, `NSSF`, and `AL` meanings.
- Security Protocol `00h` discovery behavior and `EAh` NVMe-specific selector values from Base Spec.
- Base/SPC-5 boundary statement.

## This Folder Does Not Own

- PyNVMe API call syntax.
- SPC-5 security protocol payload definitions.
- TCG / RPMB protocol payload details.
- Security Send payload format for a specific protocol.
