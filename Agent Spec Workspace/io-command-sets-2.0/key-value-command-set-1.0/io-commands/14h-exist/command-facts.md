# KV Exist Command Facts

| Item | Value |
|---|---|
| Command | Exist |
| Opcode | `14h` |
| Source | Key Value Command Set 1.0 section 3.2.4, Figures 23-26 |
| Data direction | No data transfer |
| NSID | Uses Namespace Identifier |
| Payload | No command data payload |

Exist returns completion status indicating whether the specified KV key exists. Success means the key exists.
