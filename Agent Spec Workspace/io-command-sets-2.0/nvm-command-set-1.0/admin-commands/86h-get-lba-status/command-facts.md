# NVM Get LBA Status Command Facts

| Item | Value |
|---|---|
| Command | Get LBA Status |
| Base Admin opcode | `86h` |
| Owning spec | NVM Command Set Specification 1.0 |
| Source section | NVM Command Set section 4.2.1; capability context in section 5.8.1 |
| Source figures | Figures 107-112 |
| Command type | I/O Command Set specific Admin command hook |
| Data direction | Controller to host |
| Queue | Admin Submission Queue / Admin Completion Queue |
| Namespace scope | Uses `NSID`; Base opcode table does not support `NSID=FFFFFFFFh` for this command. |
| Returned data | LBA Status Descriptor List |

## Core Behavior

The command requests information about Potentially Unrecoverable LBAs in a specified namespace and LBA range.

If the command completes successfully, the controller returns an LBA Status Descriptor List. The list may contain zero or more LBA Status Descriptor Entries. `NLSD=0` is a valid successful result and means no descriptor entries were returned in that data structure.

## Capability Context

To support the Get LBA Status capability, the NVM subsystem is expected to expose the related capability and supporting mechanisms:

| Required surface | Why it matters |
|---|---|
| Identify Controller `OACS` Get LBA Status capability | Gates whether the command is supported. |
| Optional Asynchronous Events Supported: LBA Status Information Notices | Allows LBA Status Information Alert events. |
| LBA Status Information log page `LID=0Eh` | Gives namespace/range hints for later Get LBA Status commands. |
| Log Page Offset and extended Number of Dwords support | Needed for reading the LBA Status Information log page. |
| Feature `15h` LBA Status Information Attributes | Provides poll/report interval behavior. |

## Report Types

| Report type | Meaning | Delay expectation |
|---|---|---|
| Tracked LBAs | Potentially Unrecoverable LBAs already associated with physical storage by background scan or other mechanisms. | Returned without significant delay. |
| Untracked LBAs | Potentially Unrecoverable LBAs generated by a scan originated by Get LBA Status with `ATYPE=10h`. | Significant delay may occur. |
