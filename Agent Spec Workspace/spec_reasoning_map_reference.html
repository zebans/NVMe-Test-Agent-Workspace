Test Flow Overview

FWUpdateCA0

Test Purpose 使用不同的 firmware transfer length，將 FW/CA.bin 下載至 controller，接著以 Firmware Commit CA=0 將 firmware image 寫入指定的 firmware slot，觀察不同 transfer length 與 target slot 組合下的 command behavior。
Main Behaviors
SPEC 直接對應 SPEC_AGENT 推斷 來源名稱需要解讀 非 SPEC 行為
  1. 01

    Environment Preparation

    需要解讀
    • PreTest SPEC 未直接辨識
    Agent 推斷
    PreTest 應為測試平台的環境初始化行為，不是 NVMe command。它可能包含 controller 初始化、fixture 準備或先前狀態清理，但來源沒有提供實際內容。
    Behavior name → Test setup context → Test-platform action
    SPEC Index
    SPEC ReferenceResult
    Direct SPEC referenceNone. PreTest is interpreted as a test-platform preparation behavior.
  2. 02

    Firmware Image Download

    SPEC Command
    • CMD: FwDownload Command mapping
    Agent 推斷
    FwDownload 並非 SPEC 的正式 command 名稱；根據 firmware image、輸入檔案與 transfer length，推斷其對應 Firmware Image Download command。
    FwDownload + firmware file + transfer length → Firmware Image Download
    • FILE: FW/CA.bin Payload source
    Agent 推斷
    FILE 是 test platform 用來指定 firmware 檔案的來源，其檔案內容應成為 Firmware Image Download command 的 data payload。
    • TXLEN: 20000 / 40000 / 80000 / 100000 / 200000 Field translation
    Agent 推斷
    TXLEN 應為 test platform 定義的 transfer length。由 20000 對應 128 KiB 的來源描述，推斷數值採 hexadecimal byte length，再轉換為 SPEC 使用的 OFST 與 NUMD。 OFST = image_offset_bytes / 4 NUMD = transfer_size_bytes / 4 - 1
    SPEC 連接
    Firmware Image Download 使用 OFST 表示 image offset，使用 NUMD 表示本次傳輸的 DWORD 數量減一。

  3. 03

    Wait Commands

    Non-SPEC Behavior
    • CMD: SLEEP
    • TIME: 2 seconds
    Agent 解讀
    這是 test platform 加入的 timing behavior，不是 NVMe command 或 SPEC field。來源沒有說明固定等待兩秒是在等待非同步處理、平台穩定，或只是 legacy test behavior。
    SPEC Index
    SPEC ReferenceResult
    Direct SPEC referenceNone. SLEEP and TIME are interpreted as test-platform timing behavior.
  4. 04

    Firmware Commit

    SPEC Command
    • CMD: FwCommit Command mapping
    Agent 推斷
    根據來源同時提供 CA 與 FS，推斷 FwCommit 對應 SPEC 的 Firmware Commit command。
    FwCommit + CA + FS → Firmware Commit
    • CA: 0 SPEC Field
    SPEC 連接
    Commit Action 0 表示將已下載的 firmware image 寫入指定 firmware slot，不要求立即 activation。
    • FS: 1 or 2 SPEC Field
    SPEC 連接
    Firmware Slot 欄位指定下載完成的 firmware image 要寫入的目標 slot。
